# Menu inventory observations

Observed in the installed TextEdit application on macOS 27.0.1. Menu contents depend on the front document and selection. Shortcut coverage and all enabled-state changes have not been exhaustively measured.

The application menu contains app information, settings, Services, visibility commands, and quit choices. The menu bar contains document, editing, formatting, view, window, and help categories.

The document menu includes creating and opening documents, recent files, closing documents, saving and saving under another name, making a duplicate, renaming or moving the file, reverting to a prior state, exporting a PDF, showing document properties, page setup, and printing. In an untouched document, save-related and print commands can be disabled depending on document state.

The editing menu includes undo and redo, Cut, Copy, Paste, Paste and Match Style, Delete, Select All, insertion of line/paragraph/page breaks, adding attachments and links, find and replace, spelling and grammar, text substitutions, case transformations, speech, dictation, and symbol input. Undo and Redo menu titles include the action name (for example, “Undo Make Rich Text”) and are disabled when no action is available. The Find submenu includes Select Line. Cut, copy, delete, and selection-dependent find commands are disabled when the document has no relevant selection.

The formatting menu includes font and character styles, size changes, color selection, text alignment, paragraph direction, ruler controls, spacing, rich/plain conversion, editing protection, wrapping to page boundaries, hyphenation, vertical layout, lists, and tables. The toolbar and ruler shown in a rich-text document provide formatting and paragraph controls; plain-text documents omit the rich-text formatting toolbar and ruler.

The view menu offers window presentation commands. Exact key equivalents, every menu item's enabled/disabled conditions, window restoration, and behavior of the PDF, print, table, list, and find panels remain to be measured.
